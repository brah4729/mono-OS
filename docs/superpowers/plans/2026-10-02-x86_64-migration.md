# x86_64 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port MonoOS (Dori kernel, Oki DE, libc, userland) from 32-bit i686 to 64-bit x86_64 long mode, replacing the i686 build entirely, with every boot stage verified by an automated QEMU serial-log test.

**Architecture:** GRUB still loads the kernel via Multiboot2 in 32-bit protected mode. A new 32-bit trampoline in `boot/multiboot.asm` checks for long mode, identity-maps the first 4 GiB with 2 MiB pages, enables PAE + EFER.LME + paging, and far-jumps into 64-bit code that calls `kernel_main(magic, mbi)` using the SysV ABI (`rdi`, `rsi`). The kernel stays linked at 1 MiB (no higher-half yet), so `-mcmodel=small` works. Subsystems are brought back one by one: `kernel_main` is cut down to a minimal core in Task 2 and each later task re-adds the init calls it ports. Each stage ends with `make test-boot` green.

**Tech Stack:** `x86_64-elf-gcc` / `x86_64-elf-ld` cross toolchain, NASM (`-f elf64`), GRUB 2 `grub-mkrescue`, `qemu-system-x86_64`, bash test script. The build host is Linux, WSL, or `nix develop`. The dev machine runs Windows, so run every command below inside WSL.

**Spec:** There is no separate spec document. The requirements come from the user's request ("migrate this system into x86_64 instead of this 32 bit system") and the codebase survey recorded in `AGENTS.md` and `README.md`. The decisions locked in by this plan:
1. i686 support is dropped. There is no dual-arch build.
2. The boot path stays on GRUB + Multiboot2. No UEFI and no Limine.
3. The kernel stays identity-mapped at 1 MiB. Higher-half is out of scope.
4. Syscalls stay on `int 0x80` but switch to the Linux x86_64 register convention (`rax` = number, `rdi rsi rdx r10 r8` = args, `rax` = return). `syscall`/`sysret` is out of scope.
5. The DoriFS on-disk format must not change. Existing `monoos-disk.img` files must still mount.

## Global Constraints

- Toolchain prefix: `CROSS_PREFIX = $(HOME)/opt/cross/bin/x86_64-elf-` (override with `make CROSS_PREFIX=x86_64-elf-`).
- Kernel CFLAGS must include `-m64 -mcmodel=small -mno-red-zone -mgeneral-regs-only -fno-pic -fno-pie -ffreestanding -fno-stack-protector -Wall -Wextra -Werror`.
- Kernel LDFLAGS must include `-z max-page-size=0x1000`. Without it, ld aligns segments to 2 MiB and the Multiboot2 header can fall outside the first 32 KiB, so GRUB refuses the kernel.
- The kernel must end below `0x200000`, because the kernel heap starts at `HEAP_START = 0x200000`. The linker script enforces this.
- QEMU binary: `qemu-system-x86_64`. Flags `-m 256M -vga std` are mandatory.
- No floating point and no SSE in the kernel. `-mgeneral-regs-only` enforces this.
- Pointer↔integer casts go through `uintptr_t`. Never cast a pointer to `uint32_t`.
- Every number→string buffer must be at least `24` bytes (`UINT64_MAX` is 20 decimal digits, 16 hex digits).
- The DoriFS on-disk structs stay byte-identical: `sizeof(dorifs_superblock_t) == 4096`, `sizeof(dorifs_inode_t) == 344`.
- Code style: file header `/* path — description */`, section dividers `/* ─── Name ─── */`, serial log tags `[DORI]`, `[TEST]`, `[VMM]`, etc.
- Commit messages: Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A pre-existing DoriFS disk image from the i686 build** must still mount without being reformatted. Data loss is the worst failure here. Test: Task 7 boots the x86_64 kernel against a disk image written by the old kernel and asserts `[OK] DoriFS mounted` without `Formatting disk`.
2. **Printing a 64-bit address into a 16-byte buffer** (17 such buffers exist today) overflows the stack and corrupts state silently. Expected behavior: the full address prints. Test: Task 3's self-test prints `0xFFFFFFFFFFFFFFFF` through `utoa` and checks the string.
3. **Mapping a page inside the boot 2 MiB identity region** (ELF programs load at `0x400000`) must split the huge page without disturbing the other 511 identity mappings. Test: Task 4's self-test maps over `0x400000` and then reads a neighbour address `0x5FF000` that must still be identity-mapped.
4. **A CPU without long mode** (or QEMU started as `qemu-system-i386`) must show a readable error, not triple-fault and reboot-loop. Test: Task 2 runs the ISO under `qemu-system-i386` and asserts the `NO64` VGA path, using the serial marker `[BOOT] no long mode`.
5. **Kernel threads starting on a misaligned stack** crash later in unrelated code, because GCC assumes 16-byte alignment at function entry. Test: Task 6's context-switch self-test asserts `(frame_address & 0xF) == 0` inside the new thread.

### Mechanical porting rules (used by Tasks 5, 7, 8 — repeated in each task)

| # | 32-bit pattern | 64-bit replacement |
|---|----------------|--------------------|
| R1 | `(uint32_t)ptr` (pointer → int) | `(uintptr_t)ptr` |
| R2 | `(T*)x` where `x` is `uint32_t` | `(T*)(uintptr_t)x` |
| R3 | `char buf[16]` / `char num[16]` / `char buf[12]` used with `utoa`/`itoa` | `char buf[24]` / `char num[24]` |
| R4 | `__asm__("mov %%crN, %0" : "=r"(u32))` | Use `uint64_t` for the operand |
| R5 | `regs->eax/ebx/ecx/edx/esi/edi/eip/esp` | `regs->rax/rdi/rsi/rdx/r10/r8/rip/rsp` (see the syscall table in Task 7) |
| R6 | A struct field holding an address typed `uint32_t` | `uintptr_t` (**never** in `dorifs_*` on-disk structs) |

- [ ] **Step 1: Write the harness**

`scripts/boot-test.sh`:

```bash
#!/usr/bin/env bash
# scripts/boot-test.sh — boot an ISO headless in QEMU and assert serial-log markers
# usage: scripts/boot-test.sh <qemu-binary> <iso> <timeout-seconds> <marker>...
#        DISK=monoos-disk.img scripts/boot-test.sh ...   (attach IDE disk)
set -u
QEMU=$1; ISO=$2; T=$3; shift 3
LOG=$(mktemp)
DISK_ARGS=()
if [ -n "${DISK:-}" ]; then DISK_ARGS=(-drive "file=$DISK,format=raw,if=ide"); fi

timeout "$T" "$QEMU" -m 256M -vga std -display none -no-reboot \
    -serial "file:$LOG" -cdrom "$ISO" "${DISK_ARGS[@]}" >/dev/null 2>&1

fail=0
for m in "$@"; do
    if grep -qF -- "$m" "$LOG"; then echo "PASS: $m"; else echo "FAIL: missing '$m'"; fail=1; fi
done
if grep -qE 'PANIC|PAGE FAULT|\[TEST\].*FAIL' "$LOG"; then
    echo "FAIL: fault/test failure in log:"
    grep -E 'PANIC|PAGE FAULT|\[TEST\].*FAIL' "$LOG"
    fail=1
fi
if [ "$fail" != 0 ]; then echo "--- serial log ---"; cat "$LOG"; fi
rm -f "$LOG"
exit "$fail"
```

Run: `chmod +x scripts/boot-test.sh`

- [ ] **Step 6: Long-mode trampoline**

Replace `boot/multiboot.asm` entirely:

```nasm
; boot/multiboot.asm — Multiboot2 header, 32→64-bit trampoline, kernel entry (x86_64)
;
; GRUB enters _start in 32-bit protected mode, paging off, eax = MB2 magic,
; ebx = MB2 info physical address. We identity-map 0–4 GiB with 2 MiB pages,
; enable long mode, and call kernel_main(rdi = magic, rsi = mbi).

section .multiboot
align 8
MULTIBOOT2_MAGIC    equ 0xE85250D6
MULTIBOOT2_ARCH     equ 0              ; i386 protected-mode entry (GRUB has no 64-bit entry)
MULTIBOOT2_LENGTH   equ (multiboot_header_end - multiboot_header_start)
MULTIBOOT2_CHECKSUM equ -(MULTIBOOT2_MAGIC + MULTIBOOT2_ARCH + MULTIBOOT2_LENGTH)

multiboot_header_start:
    dd MULTIBOOT2_MAGIC
    dd MULTIBOOT2_ARCH
    dd MULTIBOOT2_LENGTH
    dd MULTIBOOT2_CHECKSUM

    ; ─── Framebuffer request tag ───
    align 8
    dw 5
    dw 0
    dd 20
    dd 1024
    dd 768
    dd 32

    ; ─── End tag ───
    align 8
    dw 0
    dw 0
    dd 8
multiboot_header_end:

; -------------------------------------------------------------------
section .bss
align 4096
boot_pml4:  resb 4096
boot_pdpt:  resb 4096
boot_pd:    resb 4096 * 4          ; 4 PDs × 512 × 2 MiB = 4 GiB
align 16
stack_bottom:
    resb 16384
stack_top:

; -------------------------------------------------------------------
section .rodata
align 8
boot_gdt64:
    dq 0                            ; 0x00 null
    dq 0x00AF9A000000FFFF           ; 0x08 kernel code, L=1
    dq 0x00CF92000000FFFF           ; 0x10 kernel data
boot_gdt64_end:
boot_gdt64_ptr:
    dw boot_gdt64_end - boot_gdt64 - 1
    dq boot_gdt64

; -------------------------------------------------------------------
section .text
bits 32
global _start
extern kernel_main

COM1 equ 0x3F8

_start:
    mov esp, stack_top
    mov edi, eax                    ; save MB2 magic (kernel_main arg 1)
    mov esi, ebx                    ; save MB2 info  (kernel_main arg 2)

    call check_long_mode
    call setup_page_tables

    mov eax, cr4                    ; PAE
    or eax, 1 << 5
    mov cr4, eax

    mov eax, boot_pml4
    mov cr3, eax

    mov ecx, 0xC0000080             ; EFER
    rdmsr
    or eax, 1 << 8                  ; LME
    wrmsr

    mov eax, cr0                    ; PG (PE already set by GRUB)
    or eax, 1 << 31
    mov cr0, eax

    lgdt [boot_gdt64_ptr]
    jmp 0x08:long_mode_start

; Halts with "NO64" on VGA + serial if the CPU lacks long mode.
; Clobbers eax, ebx, ecx, edx (edi/esi preserved).
check_long_mode:
    mov eax, 0x80000000
    cpuid
    cmp eax, 0x80000001
    jb .no_long_mode
    mov eax, 0x80000001
    cpuid
    test edx, 1 << 29
    jz .no_long_mode
    ret
.no_long_mode:
    mov dword [0xB8000], 0x4F4F4F4E ; "NO" white-on-red
    mov dword [0xB8004], 0x4F344F36 ; "64"
    mov ebx, no64_msg
.serial_loop:
    mov al, [ebx]
    test al, al
    jz .halt
    mov dx, COM1
    out dx, al
    inc ebx
    jmp .serial_loop
.halt:
    cli
    hlt
    jmp .halt

; Identity-map 0–4 GiB: PML4[0] → PDPT, PDPT[0..3] → PD[0..3], 2048 × 2 MiB pages.
; Clobbers eax, ecx.
setup_page_tables:
    mov eax, boot_pdpt
    or eax, 0b11                    ; present | writable
    mov [boot_pml4], eax

    xor ecx, ecx
.pdpt_loop:
    mov eax, ecx
    shl eax, 12
    add eax, boot_pd
    or eax, 0b11
    mov [boot_pdpt + ecx * 8], eax
    inc ecx
    cmp ecx, 4
    jne .pdpt_loop

    xor ecx, ecx
.pd_loop:
    mov eax, ecx
    shl eax, 21                     ; ecx × 2 MiB
    or eax, 0b10000011              ; present | writable | huge
    mov [boot_pd + ecx * 8], eax
    mov dword [boot_pd + ecx * 8 + 4], 0
    inc ecx
    cmp ecx, 2048
    jne .pd_loop
    ret

section .rodata
no64_msg: db "[BOOT] no long mode: CPU is not x86_64", 10, 0

; -------------------------------------------------------------------
section .text
bits 64
long_mode_start:
    mov ax, 0x10
    mov ss, ax
    mov ds, ax
    mov es, ax
    mov fs, ax
    mov gs, ax

    mov edi, edi                    ; zero-extend magic (upper half undefined after mode switch)
    mov esi, esi                    ; zero-extend MB2 info address
    call kernel_main

    cli
.hang:
    hlt
    jmp .hang
```

The serial line is written without initialising the UART, which works under QEMU. On real hardware the VGA text is the guaranteed signal.

```c
/* kernel/gdt.c — x86_64 Global Descriptor Table + TSS for Dori kernel */

#include "../include/gdt.h"
#include "../include/string.h"

#define GDT_ENTRIES 7   /* null, kcode, kdata, ucode, udata, tss(lo), tss(hi) */

static uint64_t         gdt[GDT_ENTRIES];
static struct gdt_ptr   gp;
static struct tss_entry tss;

/* Code/data descriptor: base and limit are ignored in long mode except for flags */
static uint64_t make_segment(uint8_t access, uint8_t flags) {
    return ((uint64_t)0xFFFF)                    /* limit 15:0  */
         | ((uint64_t)access << 40)
         | ((uint64_t)0xF << 48)                 /* limit 19:16 */
         | ((uint64_t)(flags & 0xF0) << 48);     /* G, D/B, L   */
}

static void write_tss_descriptor(int num) {
    uint64_t base  = (uint64_t)(uintptr_t)&tss;
    uint64_t limit = sizeof(tss) - 1;

    gdt[num] = (limit & 0xFFFF)
             | ((base & 0xFFFFFF) << 16)
             | ((uint64_t)0x89 << 40)            /* present, 64-bit TSS (available) */
             | (((limit >> 16) & 0xF) << 48)
             | (((base >> 24) & 0xFF) << 56);
    gdt[num + 1] = base >> 32;
}

void gdt_init(void) {
    memset(&tss, 0, sizeof(tss));
    tss.iomap_base = sizeof(tss);

    gdt[0] = 0;
    gdt[1] = make_segment(0x9A, 0xA0);   /* kernel code: L=1, G=1 */
    gdt[2] = make_segment(0x92, 0xC0);   /* kernel data */
    gdt[3] = make_segment(0xFA, 0xA0);   /* user code, DPL3, L=1 */
    gdt[4] = make_segment(0xF2, 0xC0);   /* user data, DPL3 */
    write_tss_descriptor(5);

    gp.limit = sizeof(gdt) - 1;
    gp.base  = (uint64_t)(uintptr_t)&gdt;

    gdt_flush((uint64_t)(uintptr_t)&gp);
    tss_flush();
}

void gdt_set_kernel_stack(uint64_t rsp0) {
    tss.rsp0 = rsp0;
}
```

```c
 * The boot trampoline identity-maps 0–4 GiB with 2 MiB pages. We keep using
 * that PML4; page tables we allocate come from the PMM (< 256 MiB, so they
 * are reachable through the identity map).
 */
static page_table_t* pml4 = 0;

#define IDX(virt, shift) (((virt) >> (shift)) & 0x1FF)

static void page_fault_handler(registers_t* regs) {
    uint64_t addr;
    __asm__ volatile ("mov %%cr2, %0" : "=r"(addr));

    vga_set_color(VGA_WHITE, VGA_RED);
    vga_puts("\n*** PAGE FAULT ***\n  Address: ");
    vga_put_hex(addr);
    vga_puts("\n");

    serial_puts("[PAGE FAULT] addr=");
    serial_put_hex(addr);
    serial_puts(" rip=");
    serial_put_hex(regs->rip);
    serial_puts(" err=");
    serial_put_hex(regs->err_code);
    serial_puts("\n");

    cli();
    for (;;) hlt();
}

static inline void flush_tlb_all(void) {
    uint64_t cr3;
    __asm__ volatile ("mov %%cr3, %0" : "=r"(cr3));
    __asm__ volatile ("mov %0, %%cr3" : : "r"(cr3) : "memory");
}

static page_table_t* alloc_table(void) {
    uint64_t phys = pmm_alloc_frame();
    if (!phys) kernel_panic("[VMM] out of frames for page tables");
    memset((void*)(uintptr_t)phys, 0, PAGE_SIZE);
    return (page_table_t*)(uintptr_t)phys;
}

/* Return the next-level table for *entry, creating it or splitting a 2 MiB page. */
static page_table_t* next_level(pte_t* entry, uint64_t flags) {
    uint64_t user = flags & PAGE_USER;

    if (!(*entry & PAGE_PRESENT)) {
        page_table_t* t = alloc_table();
        *entry = (uint64_t)(uintptr_t)t | PAGE_PRESENT | PAGE_WRITABLE | user;
        return t;
    }

    if (*entry & PAGE_HUGE) {
        uint64_t base = *entry & PAGE_ADDR_MASK & ~0x1FFFFFUL;
        uint64_t keep = *entry & (PAGE_PRESENT | PAGE_WRITABLE | PAGE_USER);
        page_table_t* t = alloc_table();
        for (uint64_t i = 0; i < 512; i++) {
            t->entries[i] = (base + i * PAGE_SIZE) | keep;
        }
        *entry = (uint64_t)(uintptr_t)t | PAGE_PRESENT | PAGE_WRITABLE | user;
        flush_tlb_all();
        return t;
    }

    *entry |= user;
    return (page_table_t*)(uintptr_t)(*entry & PAGE_ADDR_MASK);
}

void vmm_map_page(uint64_t phys, uint64_t virt, uint64_t flags) {
    page_table_t* pdpt = next_level(&pml4->entries[IDX(virt, 39)], flags);
    page_table_t* pd   = next_level(&pdpt->entries[IDX(virt, 30)], flags);
    page_table_t* pt   = next_level(&pd->entries[IDX(virt, 21)], flags);
    pt->entries[IDX(virt, 12)] = (phys & PAGE_ADDR_MASK) | PAGE_PRESENT | flags;
    __asm__ volatile ("invlpg (%0)" : : "r"(virt) : "memory");
}

/* Walk without creating; returns the PTE pointer or 0. A huge PD entry returns 0. */
static pte_t* find_pte(uint64_t virt, uint64_t* huge_base) {
    *huge_base = 0;
    pte_t e = pml4->entries[IDX(virt, 39)];
    if (!(e & PAGE_PRESENT)) return 0;
    page_table_t* pdpt = (page_table_t*)(uintptr_t)(e & PAGE_ADDR_MASK);

    e = pdpt->entries[IDX(virt, 30)];
    if (!(e & PAGE_PRESENT)) return 0;
    page_table_t* pd = (page_table_t*)(uintptr_t)(e & PAGE_ADDR_MASK);

    e = pd->entries[IDX(virt, 21)];
    if (!(e & PAGE_PRESENT)) return 0;
    if (e & PAGE_HUGE) {
        *huge_base = (e & PAGE_ADDR_MASK & ~0x1FFFFFUL) | 1;   /* low bit = "is huge" */
        return 0;
    }
    page_table_t* pt = (page_table_t*)(uintptr_t)(e & PAGE_ADDR_MASK);
    return &pt->entries[IDX(virt, 12)];
}

void vmm_unmap_page(uint64_t virt) {
    uint64_t huge;
    pte_t* pte = find_pte(virt, &huge);
    if (!pte) return;                     /* unmapped, or inside a boot huge page: leave it */
    *pte = 0;
    __asm__ volatile ("invlpg (%0)" : : "r"(virt) : "memory");
}

uint64_t vmm_get_physical(uint64_t virt) {
    uint64_t huge;
    pte_t* pte = find_pte(virt, &huge);
    if (huge) return (huge & ~1UL) + (virt & 0x1FF000UL);
    if (!pte || !(*pte & PAGE_PRESENT)) return 0;
    return *pte & PAGE_ADDR_MASK;
}

void vmm_init(void) {
    uint64_t cr3;
    __asm__ volatile ("mov %%cr3, %0" : "=r"(cr3));
    pml4 = (page_table_t*)(uintptr_t)(cr3 & PAGE_ADDR_MASK);
    isr_register_handler(14, page_fault_handler);
    serial_puts("[VMM] 4-level paging, boot identity map 0-4 GiB adopted\n");
}
```

```c
    }
    if (h->e_ident[4] != ELFCLASS64)  { serial_puts("[ELF] Not ELF64\n");          return -1; }
    if (h->e_ident[5] != ELFDATA2LSB) { serial_puts("[ELF] Not little-endian\n");  return -1; }
    if (h->e_type != ET_EXEC)         { serial_puts("[ELF] Not ET_EXEC\n");        return -1; }
    if (h->e_machine != EM_X86_64)    { serial_puts("[ELF] Not x86_64\n");         return -1; }
    if (h->e_phnum && h->e_phentsize != sizeof(elf64_phdr_t)) {
        serial_puts("[ELF] Bad phentsize\n");
        return -1;
    }
    if (h->e_phoff + (uint64_t)h->e_phnum * sizeof(elf64_phdr_t) > size) {
        serial_puts("[ELF] Program headers past EOF\n");
        return -1;
    }
    return 0;
}

int elf_load(const void* data, uint64_t size, uint64_t* entry_point) {
    if (elf_validate(data, size) != 0) return -1;

    const elf64_ehdr_t* h = (const elf64_ehdr_t*)data;
    const uint8_t* file = (const uint8_t*)data;

    for (uint16_t i = 0; i < h->e_phnum; i++) {
        const elf64_phdr_t* ph = (const elf64_phdr_t*)(file + h->e_phoff + (uint64_t)i * h->e_phentsize);
        if (ph->p_type != PT_LOAD || ph->p_memsz == 0) continue;

        if (ph->p_offset + ph->p_filesz > size || ph->p_filesz > ph->p_memsz) {
            serial_puts("[ELF] Segment out of bounds\n");
            return -1;
        }

        uint64_t start = ph->p_vaddr & ~(uint64_t)(PAGE_SIZE - 1);
        uint64_t end   = (ph->p_vaddr + ph->p_memsz + PAGE_SIZE - 1) & ~(uint64_t)(PAGE_SIZE - 1);
        uint64_t flags = PAGE_WRITABLE | PAGE_USER;

        for (uint64_t va = start; va < end; va += PAGE_SIZE) {
            uint64_t frame = pmm_alloc_frame();
            if (!frame) { serial_puts("[ELF] Out of physical memory\n"); return -1; }
            vmm_map_page(frame, va, flags);
        }

        if (ph->p_filesz) memcpy((void*)(uintptr_t)ph->p_vaddr, file + ph->p_offset, ph->p_filesz);
        if (ph->p_memsz > ph->p_filesz) {
            memset((void*)(uintptr_t)(ph->p_vaddr + ph->p_filesz), 0, ph->p_memsz - ph->p_filesz);
        }
    }

    *entry_point = h->e_entry;
    serial_puts("[ELF] Entry point: ");
    serial_put_hex(h->e_entry);
    serial_puts("\n");
    return 0;
}
```
